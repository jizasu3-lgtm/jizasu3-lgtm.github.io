Shorts Uploader

Privacy Policy

Last updated: October 16, 2026

This policy explains how Shorts Uploader ("the tool") handles information. The tool is a personal tool used only by its developer to upload videos to the developer's own YouTube channel.

Use of YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Information is also handled under the Google Privacy Policy.

Information the tool accesses

  • The tool requests only the Google OAuth scope https://www.googleapis.com/auth/youtube.upload, which allows it to upload videos to the authorized channel.
  • It does not request or read the user's name, email address, contacts, viewing history, comments, analytics or any other account data.
  • It receives the ID of each video it uploads, and saves that ID and the video URL on the developer's computer to avoid uploading the same video twice.

How information is stored

  • The OAuth access token and refresh token are stored only on the developer's own computer.
  • No information is sent to any server other than Google's.
  • The tool does not use cookies, analytics or advertising.

Sharing

The tool does not sell, share or transfer any information received from Google APIs to any third party.

Shorts Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time from the Google security settings page. Deleting the stored token file on the developer's computer removes all stored credentials. To request deletion of any stored data, contact the address below.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
