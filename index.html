Shorts Uploader

Shorts Uploader is a personal tool that uploads short videos to the developer's own YouTube channel. The videos are produced on the developer's own computer, and the tool sends each finished video file, with its title, description and tags, to YouTube using the YouTube Data API.

The tool is used only by its developer for a single YouTube channel. It is not offered to other users.

What the tool does

  • Signs in with Google OAuth and requests only the youtube.upload scope.
  • Uploads finished video files to the authorized channel.
  • Sets the title, description, tags, category and disclosure settings (made for kids, altered or synthetic content) for each upload.

It does not read, change or delete any other data in the YouTube account.
